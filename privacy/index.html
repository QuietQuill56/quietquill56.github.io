Ami Personal Dashboard — Privacy notice

Effective date: November 2, 2026.

Purpose and access

Ami Personal Dashboard is a personal application operated by its owner on a local Mac. Its Google Calendar integration requests the calendar.events.readonly permission. That permission allows reading events from calendars accessible to the authorized Google account; the application is configured to query only the owner's selected calendars. It does not request permission to create, edit or delete calendar events.

The integration retrieves event information to display the owner's schedule, distinguish scheduled work blocks, identify explicitly titled deadline reminders, and show birthday reminders. Google responses may include event details beyond the fields retained locally. The application reads titles, event identifiers, dates and times, timezone information, cancellation/update information, recurrence identifiers and descriptions needed for classification. The normalized schedule cache retains identifiers, titles, dates/times, classification and relevant update/deadline information. The birthday cache retains birthday names, dates and event/series identifiers.

Local storage and retention

The application stores Google authorization credentials and cached schedule/birthday data in its local runtime directory on the owner's Mac. Credential files use owner-only filesystem permissions; this application does not itself encrypt them with Keychain. Successful complete refreshes replace cached snapshots. An unsuccessful refresh or revoked Google permission does not automatically erase previously saved local caches. Local files, copies and device backups remain until the owner removes them.

The owner can revoke this application's Google access in their Google Account's third-party connections settings. Revocation stops future authorized access but does not itself delete data already stored locally. The owner can request or carry out removal of the application's local caches and credentials. This does not delete events from Google Calendar.

Sharing and use

The calendar integration communicates with Google's authorization and Calendar API services. Its code does not upload calendar records to this public information website or an advertising or analytics service. The calendar integration is not designed to sell calendar information, serve advertisements, or train AI models on calendar data.

The owner may separately choose to use assistants, exports or other services with their data. Those owner-directed actions are separate from the local calendar integration and are not covered by a claim that data can never leave the Mac.

This public information website

These informational pages do not contain calendar events or login credentials and do not provide dashboard sign-in. The pages include no forms, analytics scripts or tracking pixels. The website is hosted by GitHub Pages. GitHub states that it logs and stores visitors’ IP addresses for security purposes. GitHub handles that hosting information under its Privacy Statement.
